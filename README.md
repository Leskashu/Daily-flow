# Daily Flow

PWA-трекер привычек в стиле editorial luxury.

## Что есть
- отметка привычек тапом
- прогресс дня
- серия дней
- история последних 7 дней
- офлайн-режим
- установка на iPhone через «На экран Домой»

## Публикация через GitHub Pages
Открой Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

После публикации сайт будет доступен по адресу:
`https://leskashu.github.io/Daily-flow/`

На iPhone открой ссылку в Safari → Поделиться → На экран Домой.
